# Everglen asset expansion

Added runtime atlases for:
- SoppyCraft growing plants: six plant families with three 32px growth stages each.
- User-supplied ruins/furniture sheet: seven rock nodes, seven grave/marker sprites, and two crates.

The plant pack license permits use in personal/commercial games but prohibits redistribution of the asset files as-is. The runtime atlas is a generated game atlas. Attribution is optional; SoppyCraft credit is appreciated.

The ruins/furniture source was supplied directly for Everglen. Its redistribution terms were not included with the upload, so public asset release should be cleared before shipping the source art outside the game.
