# Everglen Audit Status

The deep runtime invariant audit suite is implemented in `everglen_audit_tests.js`.

Run `window.EVERGLEN_DEEP_AUDIT.test()` in the game console for a structured report, or `window.EVERGLEN_DEEP_AUDIT.show()` to display the audit overlay.

This diagnostic layer is read-only and does not register a simulation system, timer, or canvas listener.
